# 杭州景点主体模型 · v0.25

景点详情展示可旋转的主体模型。灵隐寺、法喜寺、雷峰塔、小河直街和龙门古镇继续保留独立入口；湖滨银泰、奥体中心、萧山机场只在城市总览中定位，取消独立详情模型。自然景点按各自的代表景物组织，不再共用一套树木填充。

## 主体范围

| 景点 | 独立模型内容 | 资料和表达限制 |
| --- | --- | --- |
| 灵隐寺 | 主要殿堂及紧贴建筑群的内部院落 | 12 个有名称的来源建筑轮廓；去掉周边山林和道路。主要殿堂的屋檐、柱廊、窗格、台阶为外观概括，非室内或结构测绘 |
| 法喜寺 | 主要寺院建筑、黄墙和院落 | 13 个来源建筑轮廓；没有依据的殿堂名称不添加。凹形轮廓分成内部体块，避免封住天井 |
| 雷峰塔 | 五层八面塔体、重檐及遗址保护台基 | 从原有模型无损提取塔体子树，保持原有尺寸和结构；详情不再下载湖岸、山坡和周边道路 |
| 小河直街 | 连续街屋、石板巷及必要临河边缘 | 取来源中连续的 28 处街屋轮廓，不代表整条街；立面、檐口、木窗按建筑类型概括 |
| 龙门古镇 | 三进厅堂与天井的建筑类型示意 | 依据文保资料的院落类型；缺少逐栋测绘轮廓，**不是某座具名祠堂或整座古镇的复原**。页面与导出模型均声明这一限制 |
| 奥体中心 | 仅在城市总览中定位 | 保留总览中的大小莲花；不加载独立详情 |
| 湖滨银泰 | 仅在城市总览中定位 | 保留总览中的商业建筑；不加载独立详情 |
| 萧山机场 | 仅在城市总览中定位 | 保留总览中的机场；不加载独立详情。旧详情地址自动返回城市 |
| 西湖 | 两堤、石桥、岛上亭台、三座石塔与柳树游船 | 完整来源湖形不变；苏堤六桥等路径保留来源中心线。三座石塔围绕一个来源石塔点进行组团概括，间距和尺寸并非逐塔测绘 |
| 西溪湿地 | 秋雪庵周边水巷的一段芦苇湿地、柳树、摇橹船和一处来源街屋 | 取南侧紧凑池塘群，非完整景区。没有可靠的秋雪庵建筑轮廓，因此没有用无名街屋冒充秋雪庵 |
| 千岛湖 | 岛峰、连续林冠、浅色岸带和游船 | 岛岸和 DEM 沿用来源；浅色消落带为观看尺度下的外观表达，不对应某日实测水位，船位不代表固定航线 |
| 天目山 | 古柳杉森林类型、阔叶树、林下蕨草与登山石径 | 取来源步道周围约 614 × 440 m 的森林，高差 1.15 倍；单株古树的位置与株号没有测绘，不将代表树命名为“大树王”。下方竖直面是模型裁切面，不是真实悬崖 |

## 建筑依据

- [灵隐寺官方：千年古寺，大慈灵隐](https://www.lingyinsi.org/detail_44_7946.html)：中轴殿堂序列、大雄宝殿三重檐、药师殿重檐等形制。
- [灵隐寺官方：大殿的复建](https://www.lingyinsi.org/detail_46_18884.html)：大雄宝殿总高及开间资料。实现保留三重檐与七间正面节奏；斗拱、瓦垄、柱径等是概括构件，不能用作工程依据。
- [杭州文保导览：龙门建筑群](https://wbdl.hzwbzx.cn/house?id=160)：两至三进天井院落、传统厅堂与民居的空间类型。未据此编造具名建筑坐标或宣称测绘复原。
- [Foster + Partners：Apple Westlake, Hangzhou](https://www.fosterandpartners.com/projects/apple-westlake-hangzhou)：通高玻璃立面与建筑总高。模型保留外部体量，未复原悬挑楼板等内部结构。
- 其余来源延续[独立景点原始资料](hangzhou-place-details-sources.md)、[标志建筑来源](../data/hangzhou-atlas/signature-buildings-NOTICE.md)、[机场来源](../data/airports/NOTICE.md)、[雷峰塔来源](leifeng-real-sources.md)及[西湖来源](westlake-geographic-sources.md)。

地图轮廓与名称并不等同于建筑立面的测绘资料。例如，来源将灵隐寺中轴的一处建筑标为“灵隐寺文物展厅”，本版保留来源名称，没有擅自将它更名为法堂。法喜寺来源中未标名的殿堂继续不显示推测名称。

## 实现与再利用

西湖使用 [OSM 关系 2308774](https://www.openstreetmap.org/relation/2308774)，千岛湖岛群使用 [OSM 关系 162908](https://www.openstreetmap.org/relation/162908) 的完整内环成员。原始 API 响应和请求范围保存在 `data/scenes/hangzhou-subjects/sources/`，运行时只请求当前景点的派生资料，不下载这些原始响应。

水体附近的 DEM 与矢量水位不完全吻合。派生模型将低于邻近水位的岸地提升到水位以上 0.65 m，保持水平岸线不变；西湖与千岛湖重采样本地已归档的高程瓦片，并限制孤立的正向高程尖刺。原始数据未修改，这些处理明确记录于各资料包，不作为真实岸高或工程尺寸。

- 共享实体构件：`src/scenes/subject-kit.js`，屋面、瓦垄、柱廊、概括斗拱、窗格、台阶、街屋和商业立面。它们可用于其他城市的对应建筑类型；具体轮廓和组合仍需各自来源。
- 建筑主体：`src/scenes/hangzhou-subject.js`；山水主体：`src/scenes/natural-subject.js`。每次仅加载当前景点，切换时由现有资源池释放。
- 数据派生脚本：`scripts/build-hangzhou-subjects.py`、`scripts/build-hangzhou-natural-subjects.py`；雷峰塔提取脚本：`scripts/extract-leifeng-subject.py`。派生数据记录原文件哈希，不修改城市总览数据。
- 相机按当前窗口和实际几何顶点取景，避免高塔被裁切或建筑群只占画面一小角。
- 详情文案和加载函数使用独立对象，避免改动总览共用的地标资料而使原城市几何缓存失效。
- GLB 导出包含当前主体，而不是旧的场地模型。建筑构件无外部纹理依赖。

这是用于观赏的建筑与山水模型，尚非照片级或测量级复原。MIT 适用于程序；OSM 派生轮廓继续遵循 ODbL，地形数据及原有模型沿用其来源许可和署名。

## 自然景物依据与表达

- [杭州亚运会官网：赏秋芦飞雪，品诗意西溪](https://www.hangzhou2022.cn/hzhyn/mlhz/202111/t20211103_40835.shtml)：秋雪庵周边赏芦与摇橹游览的景物依据。本版用带茎、叶和浅色花穗的三维芦苇替代密集圆树冠；植被株数、间距和船只尺寸为微缩表达。
- [世界生物圈保护区大会：天目山—清凉峰](https://www.biosphere2025.org.cn/content/content_8872769.html)：古柳杉群落、高大树干及多样林木的依据。模型将高干、展开的层状枝冠与林下阔叶、蕨草区分开，没有声称逐株复原受保护古树。
- [中国旅游集团：千岛湖](https://www.ctg.cn/article/19411)：岛屿、碧水和金色岸带的景观依据。保留有来源的岛群，游客船只用于尺度参照。
- [杭州政协网：三潭印月](https://www.hzzx.gov.cn/cshz/content/2020-11/03/content_7845361_0.htm)：小瀛洲的岛中水体与南侧三座瓶形石塔的依据。几何使用来源湖形，石塔外观与尺寸为概括。

来源路径由 `scripts/build-natural-features.py` 从归档 OSM 节点和道路提取，写入各自然模型的 `paths`、`features` 与 `source.featureOSM`。新的 `xixi-core-osm.json` 和请求记录用于核查秋雪庵附近缺失的建筑轮廓，不由网页下载，也没有据此编造轮廓。

生成步骤：先运行 `scripts/build-hangzhou-natural-subjects.py`，再运行 `scripts/build-natural-features.py`。第二步会补充来源步道、桥位、亭址与资料哈希。西溪筛选紧凑池塘时排除大面积水体，避免一个跨区水体把取景重新扩展到整个景区。

可复用景物构件在 `src/scenes/natural-kit.js`：垂柳、柳杉类型、阔叶树、芦苇、蕨草、亭、瓶形石塔、摇橹船和游船。它们是可以修改参数的三维几何；各城市和景点的位置、植被类别及建筑组合仍需各自资料。

v0.25 的实际截图见自然景点对照页（历史记录未随公开包分发）。运行检查、来源和接地检测记录见验证说明（历史记录未随公开包分发）。检查通过与用户视觉验收是两件事；当前模型仍是风景微缩表达。
