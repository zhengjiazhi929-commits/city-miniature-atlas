# 黄鹤楼微缩场景：参考与边界

核查日期：2026-09-08。场景代码：`src/scenes/yellow-crane.js`。

## 保留的辨识特征

外观五层；层层收分的楼体；弯曲上翘的琉璃瓦屋面；朱柱、深色窗格、浅色墙面；斗拱和回廊栏杆；尖顶；台基、石阶与铜鹤。

所有建筑轮廓、屋面曲率、瓦垄、栏杆、柱、窗框、斗拱、树木和雕塑由可编辑的程序化三维几何构成。仅匾额文字使用程序生成的 Canvas 纹理。没有下载现成模型，没有将照片假装成三维景点。

## 艺术压缩及未复原部分

- 本场景是便于浏览的建筑微缩作品，不是测绘模型、古建施工资料或景区导航数据。尺寸使用任意场景单位，不声明与真实米制尺寸一致。
- 园林以圆形地台承载；塔楼、石阶、牌坊、铜鹤、树木及江水的距离和相对位置经过压缩与重组。左侧江水只表达临江意境，不表示真实岸线或游览路线。
- 屋顶使用四边套八边的概括轮廓、连续曲面与几何瓦垄，飞檐数量和每根斗拱没有逐件测绘。上下屋面的内部结构及真实受力关系不属于复原范围。
- 只建模外观五层，不复原内部九层、壁画、楼梯间、文物及游客动线。相机用于外部观察。
- “楚天极目”“气吞云梦”的场景匾额是构图中的文字元素，不声称与某一实地拍摄角度下的现存匾额位置完全对应。
- 场景参考网页中的图片保留原作者版权；开源交付仅包含本项目原创代码和程序生成内容。

## 渲染方式

重复的瓦垄、立柱、斗拱、栏杆、石板及树冠使用 `InstancedMesh` 按几何与材质批处理。自定义屋顶采用细分曲面计算法线，能够通过真实三维视角和光照显示弯曲屋面。外部应用负责环境、灯光、相机、控制器和渲染质量。

## 已执行的视觉检查

2026-09-08，在系统 Chrome 中实际加载项目的 `#/scene/yellow-crane` 页面，按 1440 × 900 视口检查正面与背面三维渲染。修正了初版屋檐与横梁交叠、松树树冠倾斜、圆形地台被视口截断，以及水面背面朝上的问题。最终默认相机能显示完整塔楼和地台；正背两面均未出现页面脚本错误。该场景在检查视角下约 39 次绘制调用、169,060 个三角形（包含应用地面），是当次浏览器渲染统计，不是跨设备性能承诺。手机布局、截图下载和 GLB 导出属于应用整体验证范围。
