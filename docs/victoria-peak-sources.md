# 太平山顶：参考与建模边界

本场景是原创程序化微缩模型，重点表现凌霄阁的弯月形上部、玻璃中庭、屋顶观景台，以及林间缆车和山下海港的空间层次。

## 外形依据

- [Farrells · Peak Tower](https://farrells.com/project/peak-tower/)：建筑设计者说明弯月形轮廓、实心基座、开放平台及悬浮屋顶的设计。模型据此塑造两端上扬、中央下垂的上部体量。
- [香港旅游发展局 · The Peak Tower](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-the-peak-tower.html)：凌霄阁与观景平台介绍。已查看页面中的[建筑外观照片](https://www.discoverhongkong.com/content/dam/dhk/data/poi/media/t/the-peak-tower/the-peak-tower-01.jpg)和[天台照片](https://www.discoverhongkong.com/content/dam/dhk/data/poi/media/t/the-peak-tower/the-peak-tower-04.jpg)，用于识别金属与玻璃立面、V 形构件、栏杆和望远镜。
- [香港旅游发展局 · The high life with Peak Tram](https://travelinluxe.discoverhongkong.com/the-high-life-with-peak-tram/)：山顶缆车、绿色车身和山林海港景观的参考。

运营方的凌霄阁资料与图库页面在本次访问中返回 403，因此不将未读到的页面作为具体细节的依据。资料核对日期：2026-09-08。

## 艺术处理与复用

建筑比例、窗格数量、山坡、步道和轨道经过重新编排。远景楼群只用于表达城市密度与海港方向；模型不是测绘成果、导航地图或真实视线分析。望远镜、行人和小建筑为配景，未复刻商业标识。

缆车沿一段缩短的坡道往返，动画由时间确定；GLB 下载保存导出时的几何位置，不包含运行控制代码。照片仅作为阅读和观察参考，没有下载后随仓库分发，也没有被贴在模型上。场景代码与程序化模型遵循仓库 MIT 许可，外链照片的权利仍属于原权利人。
