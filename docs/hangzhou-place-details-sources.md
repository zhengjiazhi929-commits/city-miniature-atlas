# 杭州独立景观的数据与表达边界 · v0.20

本轮补齐小河直街、法喜寺、灵隐寺、龙门古镇、天目山、西溪湿地、奥体中心、湖滨银泰、千岛湖和萧山机场的独立 3D 页面。西湖与雷峰塔继续使用原有场景。首页仅显示已选定的 11 个景点和 1 个机场。

这些是可旋转、可缩放、可导出的微缩景观。细节包含有来源的地形、建筑轮廓、水岸、道路，以及概括的屋面、门窗、立柱和植被。它们没有达到逐栋测绘或照片级还原精度。

## 地理来源

- [OpenStreetMap](https://www.openstreetmap.org/copyright)：独立景观使用 2026-09-11 下载的只读 map API 快照。九个区域的精确请求地址、采集时间、字节数和 SHA-256 见 [OSM 清单](../data/scenes/hangzhou-details/sources/manifest.json)。建筑只使用已获得完整坐标的轮廓；水体多边形按外环和内环重建。
- [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)：高程使用 Terrarium 编码的 z12 瓦片，约 30 m 的原始像素间距随纬度变化。逐瓦片来源和校验和见 [DEM 清单](../data/scenes/hangzhou-details/sources/dem-manifest.json)。解码后作 3×3 中值及双线性重采样，以去除孤立异常高程；未移动水岸和道路。输出网格随取景跨度变化，不能把原始瓦片间距当作成品模型的统一精度。
- 部分大河或林地关系超出 OSM 接口的取景范围，用现有杭州数据补齐。引用的城市源文件 SHA-256 写在每个景点 JSON 的 `source.cityFallbackSha256`，没有覆盖或改写原来的全市边界、主路、水系和地形。近景建筑底面在水岸和取景边界处内收 2 cm，抵消不同网格分别进行毫米舍入的误差；水岸和地形不随之移动。
- 奥体的大小莲花沿用 [标志建筑来源](../data/hangzhou-atlas/signature-buildings-NOTICE.md)；机场边界、航站楼和两条现役跑道沿用 [机场来源](../data/airports/NOTICE.md)。机场近景额外使用本次 OSM 快照中的滑行道及周边建筑。
- 灵隐寺主要殿堂名称和位置来自 OSM；大雄宝殿的重檐表达与 33.6 m 总高参考[灵隐寺官方介绍](https://lingyinsi.org/detail_46_18884.html)，药师殿重檐参考[寺院官方说明](https://www.lingyinsi.org/detail_44_7946.html)。屋檐曲线、柱距、色彩和纹饰仍为概括模型，不作为建筑测绘图。

## 每个页面的取景与简化

| 页面 | 地理骨架 | 近景表达与限制 |
| --- | --- | --- |
| 小河直街 | 河道、街巷、来源建筑轮廓 | 临河房屋、屋脊、门窗；普通房屋高度与立面有概括 |
| 法喜寺 | 寺院建筑轮廓、山地、步道 | 黄墙、深色曲面屋顶、立柱；非逐殿复原，资料缺失的殿堂不任意补位置 |
| 灵隐寺 | 殿堂轮廓、名称、地形与周边步道 | 大雄宝殿、天王殿、药师殿的屋顶层次与院落 |
| 龙门古镇 | 道路、水塘、聚落用地 | 本次 OSM 快照缺少独立房屋轮廓；院落是有来源聚落范围内的代表性排布，不能称为真实逐栋位置 |
| 天目山 | 一段西天目山地、林地及道路 | 林冠和山脊；展示一段取景区域，不是完整保护区边界 |
| 西溪湿地 | 池塘、道路、来源建筑轮廓 | 水陆交错、传统屋面与植被；不是整个景区的完整总图 |
| 奥体中心 | 钱塘江岸、周边路网、建筑轮廓 | 大小莲花的花瓣屋盖、中央场地及周边建筑 |
| 湖滨银泰 | 来源商业建筑轮廓、临街步行空间 | 门窗与屋面；入口锚点继续使用 in77 A 区原始来源轮廓的面积质心 |
| 千岛湖 | 湖区片段的真实岸线、岛屿与高程 | 林冠与山水；不是全湖，也未凭名称补建未经核实的岛上设施 |
| 萧山机场 | 两条跑道、航站楼、机坪、滑行道 | 立体航站楼与窗带；高度作 4 倍近景显示夸张，标线为示意，不能用于航空运行 |

取景经纬度范围在各自的 `data/scenes/hangzhou-details/<id>.json` 的 `bbox` 中声明。底板是这些局部取景范围，不是景区法定边界。西湖与雷峰塔的来源分别见 [西湖](westlake-sources.md)和[雷峰塔](leifeng-real-sources.md)。

## 总览的五项改动

1. 大尺度楼体继续保留占地宽度，以已有城区锚点组织低、中、高三个显示高度带。同一来源街区的变化保持一致；工业、校园、机场附近和湖边以低层为主。高度带是美术布局，不是法定分区或测得的真实楼高。
2. 机场东侧加入固定 OpenFreeMap `20260830_080001_pt` 快照的土地利用补充，2038 个城镇用地面、33 个自然覆盖面。数据在 [east-context.json](../data/hangzhou-atlas/east-context.json)。原有城市地理源保持不变；缺失的土地利用仍视为未知，没有填成虚构楼群。
3. 建筑使用街区内一致、街区间有变化的深浅色组；模型宽度仍有区别，不把所有楼拉到同一高度。
4. 原有林地以外新增 1630 株代表性城区树木：610 株街边、907 株公园、113 株院落。植被分布受来源用地、道路、水面、完整楼群占地及地形约束；这些是示意种植点，不是逐树调查数据。
5. 概览标签、左侧列表直接打开对应独立景观，支持保存图片、下载 GLB、切换景点；运行时只持有当前景观。

## v0.21 独立景点轮廓

采集矩形仅用于获取和保存地理数据。网页模型按景点主体与必要环境形成展示轮廓：小河直街、寺院、古镇、湖滨银泰和机场优先使用已存来源中的命名地物或用地轮廓，并加入明确记录的环境缓冲；山水场景使用不改变地形、水系与位置的展示取景轮廓。它们都不是法定景区边界。生成规则在 `scripts/hangzhou_detail_outline.py`，实际轮廓和方法记录在各景点 JSON 的 `displayOutline` / `outlineMethod`。

西湖使用 `scripts/build-westlake-display.py` 从原始西湖数据构建展示派生包，完整西湖多边形与六处孔洞保持不变。雷峰塔保留原有塔体与地理模型，仅裁去多余外围地面并关闭切面；不改变塔或塔基的几何。所有派生地形仍按原三角面的高度插值裁切。
