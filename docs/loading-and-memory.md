# 按区域加载与资源释放 · v0.5.1

本轮为桌面“中国 → 浙江 → 杭州 → 雷峰塔”示范链路。应用只保留**一个活动区域或景点**：跨地区导航取消并销毁旧视图，回访重新创建；同一城市内旋转、缩放和定位复用当前资源。历史窄屏样式不构成本轮移动端验收。

## 当前视图保留什么

| 视图 | 活动资源 | 退出处理 |
| --- | --- | --- |
| 全国入口 | 概化省界、轻量目录与入口三维几何 | 释放入口几何、材质、标签 |
| 浙江省份 | 本地 11 市同源展示轮廓、当前 DEM、384 格长边地形、粗层地表纹理、11 市分区几何与标签 | 取消请求；释放地形、分区、采样数组、标签与渲染器；分区不销毁借用贴图 |
| 杭州主城 | 全行政区域、当前 DEM、最多 9 个 z13 概括楼群／高清地表及统一水面 | 释放粗／细地表、裁切几何、楼群、纹理、水体索引及采样数组 |
| 杭州景点附近 | 在同一主城实例增加最多 4 个 z14 建筑瓦片 | 焦点变化或拉远时取消／释放建筑细节；主城纹理仍属于当前城市 |
| 雷峰塔地理场景 | 本地 GLB、JSON 与内嵌纹理 | 按资源租约释放几何、材质、纹理与图像；无在线 DEM worker |

当前区域直接由 Three.js 绘制，不创建隐藏的 MapLibre 实例。浙江省只调用 `loadZhejiangDisplayBoundary()` 加载同源并集轮廓，并预建当前 11 份高亮几何；不同时创建原 OSM 省面或所有城市场景。进入城市时销毁省份实例，再通过 `loadRegionBoundary()` 加载原有城市行政边界。全域与主城镜头切换复用同一杭州市域。

v0.5.1 的浙江 10 倍高差与 `vivid` 增强使用同一份 DEM 和地表资源，不新增另一层地形。`city-label-layout.js` 仅计算屏内文字偏移；定位点保持原坐标，标签与引线随当前区域释放。其他省份仍为 8 倍高差，城市为 1 倍。

## 有界数据与细节

- 区域 DEM 自动选择可覆盖当前范围的层级，保留最多 **24 个 Float32 高程瓦片**供地表、水面和建筑采样。过滤及解码完成后释放质量 worker 与 PNG 处理缓存；离开区域释放浮点数组和网格。原始分辨率不因增加网格密度而提高。
- 杭州主城读取最多 **9 个 z13 瓦片**，产生最多 **180 个源聚合楼群、18,000 建筑三角形**。应用配置统一 **60 米示意高度**；不是单栋高度数据。真实面积／距离与稳定来源顺序决定取舍，网络先后不抢占预算。
- 主城细表实际替换覆盖区的粗顶部。相同源水体跨瓦片合并为一个估算水位；地表扣除水域，平水面与陆地共享对应纹理。只裁切加载成功的覆盖，不为失败瓦片挖空底层。
- 景点约 **1.5 公里**内且镜头足够近时，最多 **4 个 z14 瓦片、30,000 建筑三角形**。请求并行、生成按固定顺序，各瓦片有固定预算份额；可以只展示部分足迹。z14 更新原纹理中的主干路，**不新增细节地形、独立纹理或动态岸线层**；已写入主城纹理的细路位置仍限于该纹理的固定存储尺寸。
- 未升级的香港、武汉等历史城市保留最多 **9 个 z14 瓦片、300,000 建筑三角形**的策略。上述建筑预算均不包含地形、水面和分区三角形，不能当作全场景上限。
- 超时、请求失败与主动取消分别处理；`coarseFailed`、`overviewFailed`、`detailErrors` 等诊断不能被“ready”字样掩盖。部分有数据不代表完整覆盖。

## 取消与销毁

`app.js` 使用导航级 `AbortController`；迟到工作不能挂回已退出区域。`regional-viewer.js` 统一停止动画、销毁控制器／标记／分区／矢量／地形和渲染器。矢量 owner 负责共享的主城纹理与水面材质；地形借用纹理，只释放自己的原始／裁切网格和材质。水体查询索引、楼群选择记录和高程数组在退出时清空。

雷峰场景只读取本地 GLB 和元数据。加载中取消时，尚未移交应用的模型由加载器释放；正常返回后交给 `scene-resources.js` 管理，最后一个纹理释放时关闭共享 ImageBitmap。进行中的 GLB 导出可短暂持有模型，完成或失败后释放，导航不应中途破坏已开始的导出。

浏览器不能取消已经导入的 JavaScript 模块，HTTP 文件缓存也可能保留。小型目录与边界索引可以复用，不把 361 个离线边界文件转成常驻三维城市。

## 观察与限制

`window.__atlas.resources` 与当前 viewer 的 `diagnostics` 可检查活动资源。杭州诊断包含概括楼群、成功覆盖瓦片、统一水体、细节建筑、预占预算与在途请求；地形诊断记录保留 DEM、worker 释放和粗顶部裁切状态。检查同一路线反复进入退出后的资源是否稳定，及旧请求是否回填。

这些是应用资源预算，**不是整个浏览器 RAM 上限**。CPU 数组、GPU 纹理／绘制缓冲、驱动、代码和界面另有开销；销毁后进程内存不保证立即下降。验证与未覆盖范围见 [QA](QA.md)，不能用历史设备截图替代当前验收。

未来全球扩展可以沿用分地区目录与单活动区域策略，但还需要新的许可、投影、跨日期变更线处理和数据年代核验；本轮没有实现全球覆盖。
