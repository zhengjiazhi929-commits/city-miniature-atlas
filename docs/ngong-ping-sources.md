# 昂坪 360：参考与建模边界

原创程序化山谷场景，以双向悬索、蓝色吊厢、塔架、山林和远处村落表现昂坪 360 的游览体验。

## 外形依据

- [昂坪 360 官方 · Cable Cars](https://www.np360.com.hk/en/cable-cars)：运营方介绍东涌至昂坪的缆车与沿途山海景观。
- 同页的[标准车厢照片](https://www.np360.com.hk/media/xnphrfs4/np360-cable-car-standard-cabin-1200px-2.jpg?v=1da60f770d6e0d0)：已查看蓝色下部、玻璃上部、浅色框架和上方悬挂结构，作为吊厢配色及结构参考。

资料核对日期：2026-09-08。没有据此宣称站房、吊厢尺寸或线路工程参数得到精确还原。

## 艺术处理与复用

场景将山谷、终点村落和站房压缩到同一沙盘。山形、塔架数量、吊厢间距、支点位置及屋顶为艺术化表达；站房是功能可辨的简化体量，不是运营建筑的完整立面复原。吊厢使用简化多边形外壳。

索道有下垂曲线，车厢沿两条索道作确定性的展示运动，吊厢保持竖直。它没有风力、载荷或真实运营控制模拟；GLB 保存下载时的场景，不包含网页运动逻辑。照片仅供观察，未复制为贴图或随仓库分发。原创场景代码和程序化几何遵循仓库 MIT 许可，参考图片的权利属于原权利人。
