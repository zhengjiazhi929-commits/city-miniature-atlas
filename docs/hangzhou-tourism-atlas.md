# 杭州示范的当前实现 · 0.0.2

默认视角聚焦杭州主城，缩放拉远可查看完整市域。此版本从本地数据构建或读取预生成几何；网页不实时下载杭州矢量瓦片。原始地理范围和显示概化分别保存。

## 数据到场景

- `data/hangzhou-atlas/scene-data.json`：来源边界、DEM、水体、主路、地类及历史锚点集合；实际对用户展示的清单由 `src/hangzhou-catalog.js` / `src/catalog.js` 决定。
- `terrain-mesh.json`：预裁水域的地形三角网格，保留岛屿和孔洞。
- `source-classifications.json`、`urban-building-clusters.json`、`urban-neighbourhoods.json`、`urban-display-envelopes.json`：来源地类与街区组织、受限显示占地；不是逐栋测量建筑清单。
- `fabric-cache.json.gz`：与 builder 源代码、实际数据、配置和 City Kit 清单哈希相匹配的派生树楼道路几何。
- `signature-buildings.json` 和对应模型模块：按来源建立的代表建筑。

## 表现规则

全域使用同一基础 Web Mercator 投影，不额外横向拉弯道路、湖岸或城区。地形使用 8 倍展示高差，保留真实高低关系；水位为 DEM 推导值。透视相机、投影、概化和夸张不等于测绘精度。

树木、楼体、主路、岸壁与景点具有几何体积。普通树楼沿来源森林/建成用地布置，按实际渲染地面求支撑并避让水、路与地标。完整楼体落在独立地基上。底座统一厚度，上部山体切面更高不意味着底座倾斜。

当前缓存含 3,380 栋代表楼、6,500 株山林树、10,000 株城区树；另有 3,600 组地面灌木。这些是显示对象数量，不是现实统计。住宅按来源街区形成温和高低节奏，商业少量强调，工业低宽；灰白/银灰/少量灰蓝配色按组分配。

道路保留来源主干类别并显示实体厚度。源数据标注桥梁才建立相应支撑，不能任意将所有道路架空。显示宽度和模型放大需与现实尺寸区分。

## 景点与覆盖

总览展示西湖、小河直街、法喜寺、灵隐寺、雷峰塔、龙门古镇、天目山、西溪湿地、奥体中心、湖滨银泰、千岛湖以及萧山机场。九处景点有独立主体模型；奥体中心、湖滨银泰及机场只在总览定位。自然景点强调各自湖形、岛屿、芦苇或山林特征；寺庙保留主要建筑群，普通城市背景不代表逐栋复原。

来源与主体范围见 [景点说明](hangzhou-subject-models.md) 和 [数据 NOTICE](../data/hangzhou-atlas/NOTICE.md)。

## 复用边界

可以复用资产加载器、表面采样、道路/岸面生成方式、材质和生命周期；不能复制杭州的地块、地标或缓存冒充另一城市。新城起步接口见 [add-a-city](add-a-city.md)。深度适配需要本地数据和参数；原始研究归档并非全部随仓库提供，见 [构建工具](../scripts/README.md)。

检查记录见 [QA](QA.md)。技术通过不表示所有细节已逐项测绘或用户最终接受该视觉版本。
