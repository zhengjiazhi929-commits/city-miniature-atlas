# 真实高程与局部异常处理

省份和城市地图使用 AWS Terrain Tiles 的公开高程，不生成随机山丘。浏览器显示前会对少量显著局部异常做过滤；因此它是用于视觉地图的概化高程，不能当作逐点测绘结果。

## 为什么需要过滤

2026-09-08 抽样检查了 34 个省级导航区域的代表瓦片，以及 6 个高山、平原、海岸和盆地对照。所有请求都可正常解码，但源数据包含局部伪影。例如香港 z11 瓦片 `11/1673/893.png` 存在 −5101 m 深点与 +1442 m 尖点；其旁边又是个位数米的地表。升至 z12 并未彻底解决问题：另有 −655 m / +2436 m 的紧邻极值。因此直接请求更高层级不能作为可靠的自动修复。

原始源：[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)。格式与解码遵循[Terrarium 说明](https://github.com/tilezen/joerd/blob/master/docs/formats.md)，署名及各上游数据条款见[Mapzen/USGS/NOAA 与其他贡献方](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)。过滤不会改变这些来源和署名要求。

## 实际算法

实现位于 `src/terrain-quality.js`：

1. 将无透明像素的 256×256 Terrarium PNG 解码为米：`R*256 + G + B/256 - 32768`。
2. 对每个内部像素计算 5×5 邻域中位数和 MAD（到中位数的绝对偏差的中位数）。只有该像素偏差 **大于 `max(160 m, 6 × MAD)`** 时，才替换为邻域中位数。
3. 最多处理三轮，让显著异常小簇在极端点移除后得到处理。每一轮从同一份输入读取，避免扫描方向偏差；没有变更时提前停止。
4. 两像素边缘保持原值，避免没有邻接瓦片资料时修改拼接边界。不做全局平滑，不把负海拔截为零；未改动的瓦片直接返回原始压缩字节。
5. 若一块瓦片需改动超过 1% 的像素，或仍有明显超出地球高程范围的数值，不继续扩大滤波，而是尝试同源较粗的真实父瓦片。最多向上三层；所有可尝试父级仍不可用时明确报错，不返回虚构的零高度瓦片。

阈值是本项目用于视觉概化的保守规则，不是地学有效性证明。陡峭但狭小的真实地形也可能受到影响；孤点修复值来自邻域，仍属于估计值。较轻的噪声、边界异常、大面积错误与源数据年代问题可能继续存在。

## 无法局部修复时的真实父瓦片回退

对被数据质量检查拒绝的瓦片，以及源端明确返回 404/410 的缺失瓦片，依次尝试同一 AWS 数据集的 `z−1`、`z−2`、`z−3` 祖先。每个祖先都直接读取并通过原有质量检查；不会递归使用已经回退过的缓存，从而突破三层上限。其他网络失败、服务端错误和取消仍直接传回地图。

找到有效祖先后，只读取目标子瓦片对应的象限。先把 RGB 解码成米，再对高程做双线性采样并编码回 256×256 Terrarium；不对 RGB 通道插值，不把负数硬裁为零。父图外侧仅使用其边缘有效样点，没有跨海岸生成平地。回退采用比请求层级粗 2–8 倍的瓦片网格；重新输出 256 像素不会恢复丢失的细节。

澳门实际问题瓦片是 `14/13362/7158.png`：最小值 −16681.51171875 m，有两个像素超出有效地球范围，且位于局部过滤刻意保留的边缘。其父图 `13/6681/3579.png` 为有效的 −0.19140625 至 5 m 海岸高程。使用父图左上象限后，输出范围为 −0.1875 至 5 m；原最坏像素位置变为父图采样得到的 2.8671875 m。父图整体零局部滤波，保留真实的低于零的海岸值。

上述裁区结果已经在浏览器 PNG 管线中与独立 NumPy 结果逐字节核对。定向全坏数据测试确认：原图加三个父级，共四个请求后明确失败，`fallbackFailures=1`，没有输出替代平地。源图地址、SHA-256 和统计见源图记录（历史记录未随公开包分发），验证见父图采样结果（历史记录未随公开包分发）及澳门实际地图（历史记录未随公开包分发）。

实际 Chrome 澳门省级页面也已通过：1440×960 下约 11.2 秒完成首次加载，地形、阴影、样式与全部瓦片均就绪，城市入口可见，页面及地图错误为零。该次共处理 66 块瓦片，只对上述问题瓦片使用一层父图，`fallbackTiles=1`、`fallbackFailures=0`、`inflightTiles=0`；实际截图已查看。结果记录于 `work/province-terrain/macao-fallback-results.json`，包含本次运行前后相同的地图模块 SHA-256。耗时只代表本机此次运行。

## 验证结果

Chrome 中实际执行了 PNG 解码、过滤、无损 PNG 编码和重新解码，共 42 个原始样本（上述 40 个加 2 次异常追踪）。结果与独立 NumPy 原型一致，所有边界像素保持不变。合计改动 **404 / 2,752,512 个像素，约 0.0147%**；这是样本范围内的修改率，不能外推为全国误差率。

| 验证对象 | 原始值 | 过滤后 | 证据含义 |
|---|---:|---:|---|
| 香港 z11 原深点像素 | −5101 m | 5.47265625 m | 显著局部异常被邻域值替代 |
| 香港 z11 原尖点像素 | 1442 m | 3.85546875 m | 同一异常簇尖点被处理 |
| 香港 z12 原尖点像素 | 2436 m | 6.66796875 m | 较细层级异常也被处理 |
| 湖北西山 z8 原深点像素 | −989 m | 304 m | 区域样点 857 m 保持不变 |
| 珠峰附近对照坐标像素 | 8715 m | 8715 m | 整块瓦片零修改，最高像素 8753 m 保留 |
| 吐鲁番盆地对照坐标像素 | −150 m | −150 m | 整块瓦片零修改，连贯负海拔保留 |

MapLibre 5.12.0 的实际双视图渲染也已通过：相同镜头、高差 1×，原始数据的巨大尖刺显著减弱，周围山形保留；无地图或页面异常。MapLibre 对异常坐标的插值查询约从 −1270.905 m 变为 5.713 m，和“单一像素”数值不同，不能混为同一测量结果。处理后仍可见较小噪声，不能宣称完全复原当地实测地表。

## 浏览器集成与资源

```js
import {installTerrainQualityProtocol, TERRAIN_QUALITY_TILES} from './terrain-quality.js';
const terrainLease = installTerrainQualityProtocol(maplibregl);
// raster-dem source:
// {tiles:[TERRAIN_QUALITY_TILES], encoding:'terrarium', tileSize:256, maxzoom:15}
// After removing this map, also call this on initialization failure:
// terrainLease.release();
```

实现遵循 [MapLibre 自定义协议接口](https://maplibre.org/maplibre-gl-js/docs/API/functions/addProtocol/)，错误通过 Promise 拒绝传回地图。支持时使用单独的 module worker 处理 PNG，避免过滤运算阻塞地图主线程；按瓦片合并同时请求，已处理 PNG 的 LRU 上限为 8 MiB / 96 块。每位请求方独立取消，一个取消不会中断其他仍需同块数据的请求。

每次安装返回独立的 `release()` 句柄。同一 MapLibre 库的活跃句柄共享一个处理 session；最后一个句柄释放后立即取消在途请求、拒绝并清空 worker 待办、终止 worker、清空处理结果及父瓦片缓存，并注销协议。重复释放无副作用；下一次安装建立全新的 session。异步解码或请求即使迟到，也不能重新写入已释放缓存。应用切换区域并移除旧地图时，应释放旧句柄，只保留当前地图所需的地形资源。

释放后仍可读取 `stats()`：`released` 表示当前句柄已释放，`leases` 为剩余句柄数，`disposed` 表示整个 session 已销毁，`pendingWorkerTasks` 为 worker 待办数。最后释放时缓存字节、缓存块数、在途与待办均归零，`worker=false`；累计处理计数保留用于诊断。Chrome 定向验证覆盖双句柄、幂等释放、真实澳门父图缓存、网络/worker/主线程解码迟到结果，以及重新进入的全新 session，证据为 `work/province-terrain/protocol-lifetime-results.json`。

`installTerrainQualityProtocol(...).stats()` 另记录 `fallbackTiles`、`parentFetches`、`parentCacheHits`、`maximumParentLevelsUsed`、`fallbackFailures`，并保留最近 16 次回退的子图/父图地址、层数、拒绝原因与输出范围。回退是分辨率降级，应在复用和 QA 时保留这些记录；它不能证明原图是何种测量或加工原因出错。

Chrome 验证包括：worker 与直接执行的像素一致、重复请求只处理一次、缓存命中、HTTP 失败透传、预先取消及并发单方取消。最新 42 样本测试中过滤耗时中位约 82 ms/块，实际双地图负载下单块约 171 ms；这些是本机观测，不是其他设备的延迟保证。缓存上限不包含 MapLibre 自身瓦片、GPU、worker 临时内存。

原始高程仍来自不同年代与分辨率的数据源，较高缩放层级可能只是重采样；过滤不补充新的测量细节。渲染若放大纵向高差，应继续显示倍率。建筑轮廓与估算楼高属于独立矢量数据来源。
